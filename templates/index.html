About Project

This project uses a Machine Learning model to predict whether a student is likely to be placed based on selected academic and skill-related information.

The Academic Placement Prediction Model is designed to assist in understanding the relationship between student performance and placement outcomes. The system accepts student information through an interactive form and provides a predicted placement status.

The prediction is generated using a trained Logistic Regression model. The model was trained using student academic and skill-related data and uses eight numerical features for prediction.

Prediction Factors

The model considers important academic and skill-related factors while generating a prediction.

📚

Academic Performance

10th percentage, 12th percentage and UG CGPA are considered as important academic factors.

⏰

Attendance

Student attendance percentage is used as one of the input factors.

💻

Technical Skills

Technical skill level is included to represent the student's technical ability.

🗣️

Communication Skills

Communication skill level is considered as another important placement factor.
